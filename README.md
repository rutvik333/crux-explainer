# Crux Explainer

A Codex skill for researching and producing original cinematic YouTube Shorts for Crux Uncovered.

Download crux-explainer.zip from the repository, extract it, and place the crux-explainer directory in your Codex skills directory. Invoke it with $crux-explainer and a topic or production request. The ZIP includes the skill instructions, production and publishing references, and a Python export verifier that uses FFmpeg and FFprobe. Rendering, web research, and licensed narration depend on the tools and accounts available in the production environment.

Example request

> $crux-explainer Find three visually demonstrable engineering questions on YouTube, pick the strongest supported angle, and produce a fact-checked cinematic Short with a clean frame and scene-specific audio.
